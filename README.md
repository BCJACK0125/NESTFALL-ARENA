# 巢城對決 NESTFALL ARENA

《巢城對決》是一款為同一台電腦、同一個鍵盤打造的雙人即時物理攻防遊戲。兩位玩家同時瞄準、蓄力、發射與防禦，在 150 秒內拆解敵方巢城並擊破核心。它把精準彈射的判斷、格鬥遊戲的即時讀招，以及派對遊戲的互害笑點濃縮進一局約兩分鐘的對戰。

遊戲採純 HTML、CSS 與 JavaScript 製作，無後端、無建置步驟，可直接部署至 GitHub Pages。

## 立即遊玩

鍵盤建議關閉輸入法，並讓遊戲分頁保持焦點。兩位玩家共用鍵盤：

| 行動 | P1 青曜 | P2 緋曜 |
|---|---:|---:|
| 調高／調低角度 | `W` / `S` | `↑` / `↓` |
| 蓄力發射／空中特技 | `F` | `J` |
| 能量盾 | `G` | `K` |
| 切換彈種 | `R` | `L` |

按住發射鍵累積力道、放開後出手；彈體仍在空中時再按同一顆鍵，可觸發該彈種的專屬特技。

## 對戰系統

- **三種彈體**：免費且靈活的疾風球、可分裂壓制的三相球，以及高成本範圍爆破的新星球。
- **主動防禦**：看準撞擊時機展開能量盾。完美格擋能化解壓力，但使用護盾會消耗與進攻共用的能量。
- **殘骸反打**：工事受損會累積廢料；集滿後自動鍛造，修復核心與城牆，讓落後方保有翻盤窗口。
- **追趕機制**：核心生命落後到門檻後獲得額外能量回復，降低雪球效應。
- **末段超載**：最後 30 秒提升對戰張力，迫使領先者繼續防守、落後者積極進攻。
- **公平結算**：時間到時同時計算核心生命與工事完整度；差距極小則判定和局。

## 本機執行

需求：Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

瀏覽器會開啟 `http://127.0.0.1:4173`。遊戲本身沒有套件依賴；npm 套件只用於本機伺服器與自動測試。

## 品質驗證

```bash
# 引擎、物理、計分與資源邊界
npm test

# 固定種子執行 4,000 場快速對局，輸出勝率與節奏報告
npm run test:balance

# 執行 200 場完整物理 bot 對局（實際彈道、碰撞、護盾與倒塌）
npm run test:physics

# 首次執行前安裝 Chromium，再跑真實瀏覽器流程
npx playwright install chromium
npm run test:browser

# 一次執行全部檢查
npm run verify
```

快速的 4,000 場 Monte Carlo 會檢查能量經濟、勝率、局長與出手密度；另有完整物理 bot 對局，真正走過瞄準、彈道、碰撞、空中特技、護盾、拆牆、核心受傷與結算。策略種子會成對交換左右位置，避免把 bot 個性誤判成場地優勢。

本版固定種子基準：

| 模擬層級 | 場次 | P1 / P2（排除和局） | 平均局長 | 核心提前擊破 |
|---|---:|---:|---:|---:|
| 能量經濟 Monte Carlo | 4,000 | 50.91% / 49.09% | 114.30 秒 | — |
| 完整物理 bot | 200 | 48.98% / 51.02% | 145.52 秒 | 19.50% |

完整物理樣本另有 4 場和局（2%）；其餘未提前擊破的對局會依核心生命優先、工事完整度次之進行判定。這些 bot 是固定的中等命中與防守策略，數字用來抓側偏與版本回歸，不代表所有真人玩家的最終勝率。

瀏覽器 smoke test 會模擬雙方蓄力發射、開盾、核心受傷、勝負結算與重新開局，並監看未捕捉的頁面錯誤。

## 部署到 GitHub Pages

1. 將專案推送到 GitHub，預設分支設為 `main`。
2. 到 repository 的 **Settings → Pages**，將 **Source** 選為 **GitHub Actions**。
3. 推送至 `main`，或在 **Actions → Deploy NESTFALL ARENA to Pages** 手動執行。

工作流程會先跑單元測試、4,000 場平衡模擬與 Chromium smoke test；全部通過後才封裝純靜態檔並部署。Pull request 只執行驗證，不會更新正式網站。

## 專案結構

```text
.
├── index.html                 # 遊戲入口與介面
├── js/
│   ├── audio.js              # 零素材 Web Audio 合成音效
│   ├── engine.js             # 共用參數、物理工具與平衡模擬
│   └── game.js               # Canvas 遊戲、輸入與畫面流程
├── tests/
│   ├── engine.test.mjs       # Node 單元／平衡護欄測試
│   ├── game-flow.test.mjs    # DOM／Canvas 無頭流程模擬
│   ├── balance-report.mjs    # 4,000 場可重現報告
│   ├── physics-report.mjs    # 完整物理 bot 對局報告
│   └── browser-smoke.spec.mjs
├── playwright.config.mjs
└── .github/workflows/pages.yml
```

本作以經典物理彈射玩法為靈感，但名稱、世界觀、角色、介面與程式均為原創設計，與其他商業遊戲品牌無關。
